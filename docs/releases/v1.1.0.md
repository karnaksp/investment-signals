# Investment Signals Core v1.1.0

Первый минорный релиз после стабильного `v1.0.0` расширяет живой набор
рыночных сигналов и сразу включает новые типы в наблюдение через Telegram.

## Новые realtime-сигналы

- `confirmed_impulse_long` / `confirmed_impulse_short` — движение цены,
  подтверждённое всплеском активности и согласованной дельтой агрессивных
  сделок; состояние стакана повышает score, но не является обязательным.
- `liquidity_vacuum` — одновременное исчезновение глубины верхних уровней
  стакана и статистически необычное расширение спреда.
- `futures_positioning` — четыре режима по сочетанию цены и изменения open
  interest: набор лонгов, набор шортов, закрытие шортов и ликвидация лонгов.
- `obi_dynamics` и `aggressive_trade_burst` переведены из встроенного
  `admin_only` в тот же realtime rollout.

Rollout-типы обходят общий cooldown по инструменту, чтобы наблюдатель мог
сравнить их на одном рыночном эпизоде. Глобальный лимит сообщений в час
остаётся защитой от шторма. Явный custom rule `admin_only` по-прежнему имеет
приоритет и может мгновенно остановить доставку конкретного типа.

## Получение и фильтрация данных

Trade subscription T-Invest теперь запрашивает `with_open_interest=true`.
Детектор строит baseline по абсолютному изменению OI между наблюдениями и
требует одновременного движения цены. Старый baseline абсолютных уровней OI
не переносится в новую семантику и безопасно прогревается заново.

Файл `conf/delivery-notional-policy.json` сохраняет базовый порог 40 млн для
старых сигналов и отключает notional gate для rollout-типов, которым оборот
либо уже подтверждён композитным правилом, либо неприменим к источнику OI.

## Обновление с v1.0.0

1. Сохраните `.env`, `conf/` и данные сервисов.
2. Получите тег `v1.1.0` и добавьте в runtime environment:
   `SIGNAL_DELIVERY_NOTIONAL_POLICY_FILE=/app/conf/delivery-notional-policy.json`.
3. Пересоберите и запустите stack; миграции базы данных в этом релизе отсутствуют.
4. Проверьте `/health`, `/ready`, runtime fingerprint `1.1.0` и delivery
   metadata новых сигналов (`delivery_channel=realtime`).
5. При шуме задайте для типа custom rule `admin_only` или отключите его порогом
   в `conf/detectors.yaml`; конфигурация перечитывается без пересборки образа.

## Откат

Верните образ или checkout `v1.0.0` и прежний `conf/detectors.yaml`. Новых
миграций и необратимых преобразований данных нет. Добавленный policy-файл
можно оставить: `v1.0.0` проигнорирует путь, если переменная не настроена.

## Граница утверждений

Новые типы выпускаются как наблюдаемые продуктовые сигналы, а не как
доказанная торговая стратегия. Приложение не исполняет сделки и не является
индивидуальной инвестиционной рекомендацией.
