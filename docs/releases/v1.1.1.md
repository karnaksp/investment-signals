# Investment Signals Core v1.1.1

Patch-релиз устраняет два эксплуатационных дефекта, обнаруженных при запуске
realtime rollout v1.1. Набор сигналов, пороги и delivery policy не меняются.

## Исправления

- Compose запускает `tinvest-migrate` как one-shot release gate после готовности
  Postgres и ClickHouse и до старта detector, API и Dagster.
- `HOME` Dagster направлен в его writable persistent volume. Daemon больше не
  уходит в restart loop при попытке записать telemetry state под non-root UID.

## Проверка после обновления

```bash
docker compose up -d --build
docker compose ps -a
curl -fsS http://localhost:38000/health
curl -fsS http://localhost:38000/ready
```

Контейнер `migrate` должен завершиться с кодом `0`; долгоживущие сервисы должны
оставаться в состоянии `Up`. Повторный запуск безопасен: migration ledger
пропускает уже применённые миграции с теми же checksum.

## Откат

Верните образы и Compose к `v1.1.0`. Миграции этого patch-релиза отсутствуют,
поэтому откат схемы не требуется. Уже применённые миграции `0100–0114`
совместимы с обоими релизами.
