# Investment Signals Core v1.1.2

Patch-релиз включает durable delivery worker в стандартный Compose-стек.
Алгоритмы и пороги realtime rollout v1.1 не меняются.

## Исправления

- `delivery-worker` стартует после успешного migration gate и healthy Postgres.
- Worker забирает новые записи из `delivery_outbox` и отправляет их в настроенный
  Telegram chat или webhook с существующей retry/dead-letter политикой.
- API получает health snapshot worker, а Prometheus — отдельный metrics target.
- Просроченные сообщения не отправляются задним числом: recovery guard переводит
  их в dead letter с `delivery_event_age_exceeded`.

## Проверка после обновления

```bash
docker compose up -d --build
docker compose ps -a
curl -fsS http://localhost:38000/health
curl -fsS http://localhost:38000/ready
```

`delivery-worker` должен оставаться `Up`, а файл
`var/runtime-health/delivery-worker.json` — показывать `state: active`.

## Откат

Верните приложение к `v1.1.1`. Новых миграций схемы нет. Перед откатом можно
остановить только `delivery-worker`; сохранённые сигналы при этом не теряются.
