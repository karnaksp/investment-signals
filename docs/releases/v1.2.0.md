# Investment Signals Core v1.2.0

Релиз расширяет анализ фьючерсов и добавляет два формата Telegram-уведомлений:
карточки позиций по отдельным активам и короткие сообщения о торговых сессиях.

## Торговые сигналы

- Пять экспериментальных сигналов сравнивают фьючерсы с разными сроками
  исполнения. Сильные наблюдения проходят проверки активности, синхронности
  и свежести. Для новых типов действует общий лимит шесть уведомлений в час.
  [Формулы и пороги](https://github.com/karnaksp/investment-signals/blob/v1.2.0/docs/futures-curve.md)
- Для всплеска объёма минимальный оборот окна составляет 500 млн ₽.
  Для пачек агрессивных сделок на TQBR и SPBFUT порог оценочного оборота
  составляет 20 млн в единицах соответствующего инструмента.
  [Правила доставки](https://github.com/karnaksp/investment-signals/blob/v1.2.0/docs/detectors.md)
- Обновление каталога подтягивает дополнительные сроки исполнения и
  спецификации. При сбоях Kafka обработка возвращается к началу полученного
  пакета, а уже записанные события отсекаются по идентификатору.

## Telegram

- По металлам и другим товарам доступны карточки из дневных данных SHFE
  и недельных отчётов CFTC и ICE. По USD/RUB, CNY/RUB и EUR/RUB
  используются дневные данные Мосбиржи. По каждому активу приходит отдельная
  картинка с коротким выводом. Лонги зелёные, шорты красные.
  [Сырьевые позиции](https://github.com/karnaksp/investment-signals/blob/v1.2.0/docs/daily-metals-positions.md) ·
  [Рублёвые пары](https://github.com/karnaksp/investment-signals/blob/v1.2.0/docs/ruble-positions.md)
- По 59 расписаниям приходят уведомления об открытии, закрытии, перерывах
  и возобновлении торгов. Сообщение содержит событие, площадку со ссылкой
  и тип рынка. Одновременные события одного типа группируются.
  [Площадки и покрытие календарей](https://github.com/karnaksp/investment-signals/blob/v1.2.0/docs/market-sessions.md)

## Сборка и совместимость

На GitHub публикуются wheel и архив исходников. Для этого тега GitHub Actions
проверяет один общий Docker-образ, поскольку изменились Dockerfile и зависимости.
Миграций базы данных в релизе нет.
