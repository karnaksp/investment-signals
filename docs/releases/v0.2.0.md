# Investment Signals Core v0.2.0

Первый tag-driven minor-релиз интегрированного движка.

## Что изменилось

- Живое теневое наблюдение отделено от исторического replay.
- Добавлены worker heartbeat, безопасное Kafka recovery и восстановление
  пропущенных свечей после временных сбоев источника.
- Добавлены ежедневная адаптивная калибровка и утренний retracement worker.
- PostgreSQL retention переведён на индексированные ограниченные пачки;
  snapshot bloat ограничен настройками vacuum.
- ClickHouse ingestion формирует меньше частей и использует native observation
  storage с управляемым сроком хранения.
- Ошибки Telegram классифицируются как постоянные либо временные и больше не
  скрываются за неоднозначным статусом доставки.

## Проверка

Тег публикуется только после полного pytest, Clean Architecture gate, strict
documentation build, JavaScript syntax check и container-level Docker smoke.

## Граница утверждений

Результаты сигналов и адаптивной калибровки остаются исследовательскими. Этот
релиз не является инвестиционной рекомендацией и не заявляет доказанное
рыночное преимущество.
