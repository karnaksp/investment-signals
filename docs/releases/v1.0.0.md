# Investment Signals Core v1.0.0

Первый стабильный релиз production-oriented движка рыночных сигналов.

## Что вошло в стабильный контракт

- Сквозной поток T-Invest → Kafka/Redpanda → detector → Postgres/ClickHouse →
  FastAPI/Admin Cockpit → Telegram/webhook/monitoring.
- Crash-replay-safe обработка, доменные границы Clean Architecture, миграции,
  health/readiness и runtime fingerprint для проверяемого развёртывания.
- Автоматическое обновление ликвидной вселенной фьючерсов через общий
  application use case, Dagster и systemd wiring.
- Порог денежного оборота для volume-spike доставки и компактные объяснимые
  Telegram-сообщения.
- Fail-closed live-shadow health, bounded candle history и устойчивый к большим
  наборам Parquet candle cache.
- Воспроизводимая документация, Admin Cockpit, Prometheus/Grafana и
  tag-driven GitHub release pipeline.

## Обновление с v0.2.0

1. Сохраните текущие `.env`, `conf/` и данные Postgres/ClickHouse.
2. Получите тег `v1.0.0` и пересоберите production image.
3. Примените ещё не применённые миграции командой `tinvest-migrate`.
4. Проверьте `/health`, `/ready`, runtime fingerprint и Admin Cockpit.
5. Убедитесь, что `conf/futures_universe.yaml` соответствует ожидаемой
   вселенной перед включением автоматического обновления.

Откат выполняется запуском образа `v0.2.0` с сохранёнными конфигурацией и
данными. Миграции релиза аддитивны; перед откатом не удаляйте новые таблицы и
столбцы.

## Проверка релиза

Публикация выполняется только после полного `pytest`, Clean Architecture gate,
strict-сборки MkDocs, проверки JavaScript, сборки Python `sdist`/wheel и
container-level Docker smoke.

## Граница утверждений

`v1.0.0` фиксирует стабильность программного и операционного контракта. Релиз
не гарантирует доходность, не исполняет сделки и не является индивидуальной
инвестиционной рекомендацией.
