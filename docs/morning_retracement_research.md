# Исследование утреннего возврата

Контур ищет условия, при которых утреннее отклонение от предыдущего закрытия
возвращается на 25%, 50%, 75% или 100%. Он не сравнивает две фиксированные
минуты: результат определяется первым касанием уровня на последующей
траектории.

Хронологическое разделение по дням сохраняется как защита от утечки, но
отдельная независимая итоговая выборка больше не является обязательным условием
показа исследовательской рекомендации. Флаг `--independent-holdout` остаётся
диагностическим признаком происхождения результата.

## Запуск

Свечи сохраняются один раз и затем переиспользуются:

```bash
uv run --extra research python scripts/research_cache_tinvest_candles.py \
  --env-file .env \
  --calendar-days 180 \
  --session-start 07:00 \
  --session-end 19:00 \
  --cache-dir var/research/tinvest_candles/v1
```

Исследование:

```bash
PYTHONPATH=. uv run --extra research \
  python scripts/research_morning_retracement.py \
  --cache-dir var/research/tinvest_candles/v1 \
  --output-dir var/research/morning_retracement_runs
```

При наличии отдельного файла сигналов можно передать
`--signal-events <файл.jsonl|файл.parquet>`. События текущего утра учитываются
только после их фактического появления, а незрелые результаты сигналов
предыдущей сессии автоматически исключаются.

## Результаты запуска

В `var/research/morning_retracement_runs/<run_id>/` создаются:

- `morning-retracement-dataset.parquet` — причинные пятиминутные снимки;
- `dataset-manifest.json` — состав данных, разделение и отпечаток;
- `model-leaderboard.csv` — сравнение текущего утра, предыдущей сессии и их
  сочетания;
- `policy-frontier.csv` — цели, ограничения убытка, защита безубытка и сроки;
- `selected-policy.json` — единственный зафиксированный кандидат и результат
  закрытой проверки;
- `report.md` — краткое объяснение на русском языке.

Итоговые доверительные границы рассчитываются повторной выборкой целых
торговых дней. Выбранные события дополнительно сравниваются с отклонениями
другого дня того же инструмента и направления, близкого времени, размера
отклонения и наблюдаемой волатильности. Отчёт показывает как частоту касания
цели, так и результат после издержек: одно не подменяет другое.

Накопленный объём сравнивается только с исторической нормой этого же инструмента
для той же минуты торгового дня. Норма строится исключительно по предыдущим
дням. В выборку также входят доля активных минут и объём на активную минуту:
так модель может отказаться от рекомендации при разреженных торгах, а не
принимать отсутствие сделок за подтверждение возврата.

## Граница применения

Продукт различает два уровня:

- **исследовательская рекомендация** — показывает направление, наблюдаемую
  частоту достижения цели, её осторожную нижнюю границу, размер выборки и
  предупреждение, что историческая доля не гарантирует следующий результат;
- **подтверждённая закономерность** — дополнительно проходит условия размера
  выборки, точности цели, вероятности результата без чистого убытка,
  устойчивости по инструментам и проверки с повышенным проскальзыванием.

Дополнительная польза признаков предыдущей сессии, наличие отдельной
независимой итоговой выборки и преимущество над сопоставимыми контрольными
событиями сохраняются в отчёте, но больше не блокируют ни рекомендацию, ни
принятие правила. Хронологическое разделение, отсутствие будущих данных,
версионированные издержки и остальные условия качества сохраняются.

Отбор инструментов разрешён только по более ранним дням с минимальным числом
эпизодов. Высокий результат одной бумаги на нескольких итоговых сделках
считается исследовательским срезом и не превращается в список разрешённых
инструментов.

Расчётный безубыток не гарантирует фактическое исполнение при разрыве цены или
недостатке ликвидности.
